# دليل مركز دراسة German Quiz

## التشغيل على ويندوز

افتح مجلد عمل الفرع المحلي، ثم شغّل الأوامر التالية باستخدام Node.js 24.

```powershell
npm ci
npm run build
npm run preview -- --host 127.0.0.1 --port 4179 --strictPort
```

افتح [المعاينة المحلية](http://127.0.0.1:4179/german-quiz/). تخزين المعاينة مستقل عن تخزين موقع GitHub Pages.

1. من شاشة اختبار المفردات استورد ملف المفردات الشخصي السابق v2. هذا يفعّل المفردات والصيغ الإضافية للتدريب.
2. افتح **مركز الدراسة** واستورد ملف **german-quiz-study-private.json** من قسم **حزمة الدراسة الخاصة**.
3. اختر **الدراسة حسب الفصل** لعرض أهداف الفصل ودروس القواعد، أو **التدريب الحر** لاختيار النطاق ونوع التدريب.
4. يتيح **إدراج المفردات المتحقّق منها آليًا** نطاقًا أوسع من المفردات الخاصة. تبقى المراجعة البشرية مميزة عن التحقّق الآلي.
5. استخدم **لوحة التقدم** لمراجعة الأخطاء وتنزيل التقدم. يمكن دمج النسخة الاحتياطية مع السجل الحالي.

## الدراسة على الآيفون

بعد الموافقة على نشر تحديث التطبيق وظهوره على الموقع، انقل ملف المفردات وحزمة الدراسة مباشرة إلى تطبيق **الملفات**. افتح الموقع في Safari. إذا أردت تثبيته، اختر **مشاركة ← إضافة إلى الشاشة الرئيسية** ثم افتحه من هناك واستورد الملفين داخل نسخة التطبيق التي تستخدمها. لا يحتاج الاستيراد إلى رفع الملفات. يجب فتح التطبيق المتصل أولًا ليحفظ واجهته للاستخدام دون إنترنت.

## ما الذي يُحفظ؟

تُحفظ حزمة الدراسة والتقدم في المتصفح. يُصدَّر سجل الدراسة من لوحة التقدم، وتُصدَّر مفردات التطبيق من شاشة المفردات. احفظ كلا الملفين عند نقل الدراسة إلى جهاز آخر.

تدريبات الكتابة تعتمد على نموذج وقائمة مراجعة ذاتية. التسجيلات الصوتية للكتاب تحتاج إلى ملفات صوتية متاحة بإذن الاستخدام. يوفّر التطبيق النطق الآلي عند وجود صوت ألماني محلي على الجهاز.
