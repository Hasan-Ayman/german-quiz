# واجهة التدريب الموحّدة

## مسارات التعلّم

| سابقًا | الآن |
| --- | --- |
| إعداد اختبار المفردات في الرئيسية وإعداد أنشطة آخر في مركز الدراسة | صفحة **التدريب** للمفردات وجميع أنشطة الحزمة |
| تحكّم منفصل في الفصول بين عرض الفصل والتدريب الحر | محدّد فصول مشترك يقبل الفصول المتباعدة ومن المستويين |
| الاستيراد والموثوقية قرب زر بدء الاختبار، والنسخ الاحتياطية أسفل مركز الدراسة | **الإعدادات** للمظهر وموثوقية المفردات والاستيراد والنسخ الاحتياطي والاستعادة |
| نتائج منفصلة حسب واجهة البدء | جلسة موحّدة تعرض نشاطًا واحدًا في كل مرة وتقدّم الجلسة والتصحيح والنتيجة وإعادة الأخطاء |

تنقّل من الشريط العلوي بين التدريب والدروس والقاموس والتقدّم والإعدادات. تفتح علامة `#/study` القديمة صفحة التدريب. تظل عناوين الاختبار والنتائج والمراجعة القديمة قابلة لفتح آخر اختبار محفوظ متى كان متوافقًا مع المفردات المستوردة.

## إعداد الجلسة

- اختيار **A1+** يعرض فصوله فقط. اختيار **A2+** يعرض فصوله فقط. خيار **A1+ وA2+** يجمعهما. عند نقل تفضيلات اختبار المفردات القديم، يتحول اختيار A2 التراكمي إلى الخيار المشترك.
- افتح **الفصول** لاختيار فصول متباعدة أو تحديد الكل. يحفظ التطبيق تحديد كل مستوى مستقلًا، ويعرض أرقام الفصول مع المستوى والعنوان. فتح **اختر الفصل للتدريب** من صفحة الدروس يضبط المحدد على ذلك الفصل.
- يعرض **تدريب مختلط** جميع أنواع التمارين المتاحة ضمن الفصول. افتح **تخصيص أنواع التمارين** لاختيار نوع أو أكثر. يمكن إجراء التمارين المصححة والبطاقات والكتابة في الجلسة نفسها. يُعرض التقييم الذاتي للبطاقات والكتابة بصورة منفصلة عن دقة الإجابات المصحّحة.
- العدد هو عدد الأسئلة الفريدة المؤهلة بعد التصفية. تستخدم الجلسة عددًا أقل عند الحاجة وتذكر العدد الفعلي. تظهر تفاصيل التغطية إذا تعذّر تمثيل بعض الفصول أو الأنواع في الجولة.
- يتضمن **خيارات متقدمة** اتجاه الترجمة ونوع الكلمة وحالة المراجعة ودرجة التطبيق ووجه البطاقة وموضوع القواعد وأنواع أسئلة المفردات الدقيقة.

## الميزات والبيانات

تظل أسئلة المفردات واتجاهات الترجمة والأدوات والجمع والصيغ، والتصريف والقواعد والحالات الإعرابية والبطاقات وإكمال الجمل وترتيبها وتصحيحها وتحويلها والقراءة والكتابة والتقييم حسب الفصل متاحة. تعرض جلسة التدريب أمثلة المفردات المؤهلة والتصحيح العربي بعد الإجابة. توفر صفحة التقدّم دفتر الأخطاء والبطاقات المستحقّة وتوزيع النشاط حسب الفصل، مع رابط لآخر اختبار مفردات سابق.

يقبل التطبيق ملف المفردات الشخصي بإصداريه 1 و2، وحزمة الدراسة بالإصدار 1. يعمل التدريب وفق المحتوى المخزّن حتى عند استيراد ملف واحد فقط. تظل المكتبتان والنسخة الاحتياطية والتقدم السابق في مخازن IndexedDB الحالية. يحفظ التطبيق خطة الجلسة وموضعها في سجلّين جديدين ضمن مخزن الدراسة القائم. يمكن استئناف الأسئلة المجاب عنها دون اتصال بعد تحديث الصفحة. يظل النص الذي لم يُسلّم داخل الصفحة الحالية.

## المعاينة المحلية

من جذر نسخة العمل التي تحتوي على الفرع `codex/unified-practice`، شغّل:

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 4180 --strictPort
```

افتح `http://127.0.0.1:4180/german-quiz/`. لهذا العنوان المحلي مساحة تخزين متصفح مستقلة عن عنوان GitHub Pages. للاختبار المحلي، استورد الملفين الموجودين لديك من **الإعدادات ← استيراد المحتوى الخاص**. عند اختبار تحديث الإصدار المنشور، يجب استخدام العنوان نفسه للتحقق من بقاء بياناته.

تقرأ اختبارات حزمة الدراسة والمفردات الخاصة المسارات المحلية عبر متغيّرات البيئة `GERMAN_QUIZ_STUDY_AUDIT` و`GERMAN_QUIZ_V2_TEST_FILE`. يمكن توجيه اختبارات الانحدار القديمة إلى مجلد العمل السابق عبر `GERMAN_QUIZ_PHASE3_FIXTURES`. تشغّل `npm run test:browser` اختبارات الواجهة على بناء الإنتاج. يقارن `tests/release-upgrade.browser.mjs` بين نسخة منشورة سابقة والبناء الحالي على عنوان محلي واحد. يمكن تحديد مجلد خارج المستودع للقطات المقارنة عبر `GERMAN_QUIZ_SCREENSHOTS`.
